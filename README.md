Entry for the [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) bounty on make.fun.

`main.py` writes a single funny line of at most 200 characters to `/output/entry.txt`. The line was picked from 15 candidates generated with a DeepSeek brainstorm and critique-picked against the judge's criteria: genuinely hilarious, an unseen twist, tight wording, fresh, and memorable.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
